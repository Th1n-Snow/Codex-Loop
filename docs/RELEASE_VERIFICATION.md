# 发布验证范围

验证目标为当前 Windows x64 发行候选，不能等同于已在另一台实体电脑验收。

## 自动检查

运行 scripts/verify-release.py：26 个模块，388 项检查通过；包含调度与窗口等待、防重复、额度解析、只读连接、临时会话自检、自动同步与失败回退、计划编辑还原、主题语言切换、图标、启动项及单实例。

源码 wheel 成功构建，新图标通过包数据配置携带。运行包采用 PyInstaller onedir，保留 _internal，用户无需安装 Python。

## 不包含在本轮发布门槛的上游旧界面测试

完整的 `unittest discover` 仍包含旧布局／原产品标识／英文固定文案／原自动更新仓库／旧 Linux 安装假设的界面用例，不能直接用于这个分支。本轮没有将这些失败隐藏成“全量测试通过”；保留旧用例供后续迁移，CI 执行 verify-release.py 中列出的当前 Windows 验证模块，并按模块隔离 Qt 全局翻译状态。独立的 Codex Loop 安装 ID 与不继承 UsageLoop 用户设置是本次有意的行为调整。

## 仍需外部环境确认

- 另一台实体电脑或全新系统的首次运行；本机没有可用的 Windows Sandbox。
- 对方的 Codex 安装版本、登录状态、网络／代理、订阅与模型可用性。
- 完整五小时窗口跨越、睡眠唤醒、开机启动与未签名软件的 SmartScreen 行为。
- Windows 10、Windows ARM、macOS、Linux 本次均未作发行承诺。
- 没有中文字体的精简 Windows 系统可能需要安装简体中文字体，或切换 English。

发布前请按照 RELEASE_PREPARATION.md 在独立电脑验收。建议首发标为 Pre-release，并随反馈再发布补丁。

## 本机独立运行验证结果

将构建产物复制到独立目录，使用空白 LOCALAPPDATA/CODEX_HOME，PATH 仅含 Windows 系统目录，移除 PYTHONHOME、PYTHONPATH 及 Qt 插件路径。独立 GUI 成功启动，未安装 Codex 时不执行预热，自动预热和开机启动默认关闭，初始中文／跟随系统配色，切换深色可持久化。此验证共享本机 Windows 系统 DLL、字体及注册表，不能替代另一台实机测试。测试中暂时变动的本机开机启动注册已恢复原值。

开启自动预热确认框已新增真实 QMessageBox 中英文检查，分段正文正确翻译；操作在测试中一律取消，不发送预热请求。

## Setup 安装包本机验收

CodexLoop-Setup.exe（约 27.4 MiB）已在独立自选路径安装，检查 exe、MIT 许可证和桌面快捷方式目标正确；已安装程序通过隔离的启动检查。卸载退出码为 0，程序文件被移除。原有工作程序的快捷方式与开机启动项已恢复。安装脚本固定显示目录页，自动创建桌面与开始菜单快捷方式；提供简体中文和 English。此测试不等同于另一台实体电脑测试，安装包尚未签名。
