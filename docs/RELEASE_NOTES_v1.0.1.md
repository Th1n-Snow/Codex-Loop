# Codex Loop v1.0.1

- 删除后台在五小时窗口结束后自动连续预热的执行入口；仅按保存的每日时间表自动预热。
- 新安装默认使用每日多个时间计划；旧 continuous 配置升级时迁移到该计划并关闭自动预热，避免意外请求。请确认时间后重新开启。
- 保留已到定时时间后等待旧窗口结束的单次队列、防重复、只读额度自动刷新及手动自检。
- 改进接近 Unix 时间原点时 Windows 不能表示的日期处理。

安装包仍支持自选路径、桌面快捷方式及中英文界面。运行需要已安装并登录的 Codex，预热会消耗少量正常额度。公开发布后的 1.0.0 不覆盖，更新按钮可发现 1.0.1。
