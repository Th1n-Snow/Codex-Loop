# Codex Loop v1.1.0

本次为功能更新：新增桃夭配色，并重新整理仪表盘外观与操作反馈。现有每日时间表、记录和额度保护规则继续保留。

## 新增与改进

- 设置新增主题色“经典薄荷／桃夭”，与跟随系统、浅色和深色独立组合，即时应用并保存。
- 桃夭浅色采用近白淡粉卡片与玫红按钮；桃夭深色采用中性炭灰背景与柔粉强调色。
- 重排仪表盘：紧凑状态横条、两列时间输入、保存按钮旁的下次检查时间、并排同步／自检按钮和横向每周额度。
- 保留当前窗口卡片左侧的状态色条；额度条继续表示剩余比例，增加独立百分比和操作图标。
- 窄窗口自动将额度与自动预热卡片上下排列，长自检结果和异常提示可换行。
- 自动预热卡片移除“暂停到明天”和“编辑预热时间”按钮；时间可在上方列表编辑，托盘保留暂停操作。
- 完善保存成功、未保存修改、修改还原和自动同步的中英文提示；更新状态显示带 v 的版本号。

## 升级说明

- 推荐下载 CodexLoop-Setup.exe，安装时选择原安装目录以覆盖升级。个人设置与记录保留。
- 升级现有用户保留主题设置；未设置主题色时默认经典薄荷。新用户仍默认简体中文、跟随系统、自动预热关闭。
- 自动预热仍只由已保存的每日时间点触发，五小时窗口到期本身不会连续发起请求；已到点的计划可按原规则等待旧窗口结束。
- 预热与自检会消耗少量正常额度；软件不增加额度、不提前重置有效窗口、不绕过限制。
